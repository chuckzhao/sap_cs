## Study Techniques

### Daily Routine (3-4 hours)

**Morning (1.5 hours)**:
- Review previous day's notes (15 min)
- Study new material (1 hour)
- Take notes and create mind maps (15 min)

**Evening (1.5-2 hours)**:
- Hands-on practice (1-1.5 hours)
- Complete exercises (30 min)

**Weekend (6-8 hours)**:
- Deep practice (4 hours)
- Projects (2-3 hours)
- Review and planning (1 hour)

### Study Methods

**Active Learning**:
1. Read module
2. Summarize in own words
3. Practice immediately
4. Teach someone else
5. Create cheat sheets

**Spaced Repetition**:
- Review after 1 day
- Review after 3 days
- Review after 1 week
- Review after 1 month

**Practice Strategy**:
- Start simple
- Increase complexity
- Create variations
- Test edge cases
- Build muscle memory

### Note-Taking System

**Use Cornell Method**:
```
┌──────────────────────────┬────────┐
│ Notes                    │ Cues   │
│                          │        │
│ Main notes here          │ Key    │
│                          │ points │
│                          │        │
├──────────────────────────┴────────┤
│ Summary                           │
└───────────────────────────────────┘
```

### Tools

**Documentation**:
- OneNote or Notion
- Mind mapping (MindMeister, XMind)
- Flashcards (Anki)
- Screenshots (Snagit)

**Practice**:
- SAP system access (essential!)
- Virtual lab environments
- Screen recording for review
- Practice log spreadsheet

**Community**:
- SAP Community account
- LinkedIn SAP groups
- Reddit r/SAP
- Study buddy/mentor
